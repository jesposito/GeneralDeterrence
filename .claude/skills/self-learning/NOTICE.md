## Changes in This Implementation

This is a complete rewrite from Python to Bun + TypeScript, adapted to match
the diary system's codebase conventions:

- Uses Bun runtime instead of Python
- Returns Result types instead of throwing exceptions
- Uses `Bun.file()` for all file I/O
- Follows kebab-case file naming and snake_case JSON fields
- Integrates with the diary skill ecosystem
